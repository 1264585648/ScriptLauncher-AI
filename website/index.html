为什么选择 ScriptLauncher AI？

不仅是一个视觉极佳的图形启动器，更是连接现代开发工作流和 AI 助手的关键桥梁。

原生 MCP 支持

内置 Model Context Protocol 服务器。AI 可以直接获取脚本列表、读取执行日志、一键启停任务。

SQLite WAL 并发引擎

采用先进的 WAL (Write-Ahead Logging) 模式，GUI 交互与 AI 并发调用互不阻塞，数据安全可靠。

全语言解释器支持

Node.js, Python, Go, Bash, PowerShell... 无论你的脚本用什么写，都能在一个面板中统一管理。

Linear 级极简设计

基于暗色美学与毛玻璃质感打造的现代化 UI。摒弃多余元素，专注效率与脚本状态呈现。

安全隔离机制

只读/执行权限分离设计，AI 只能运行你预定义的受控脚本，有效防止恶意代码注入与危险操作。

Go + Wails 高性能底座

原生编译体积小巧，内存占用低，启动极速。完全取代臃肿的 Electron 方案，如丝般顺滑。

快速上手

只需三步，让你的 AI 跑起本地脚本

1

下载并解压

获取最新的绿色发行版压缩包，解压到任意本地目录即可使用，无需繁琐的安装过程。

2

可视化管理脚本

双击启动应用，通过友好的图形界面配置和添加你常用的自动化脚本命令和执行目录。

3

配置 MCP 连接

在你的 AI 工具中添加简单的 MCP 启动参数，即可立刻授权 AI 控制和读取你的脚本日志。

MCP 一键配置

支持主流 AI 助手。将下方配置添加到对应的客户端配置文件中即可激活。

{
  "mcpServers": {
    "scriptlauncher": {
      "command": "/path/to/ScriptLauncher.exe",
      "args": ["mcp"]
    }
  }
}
配置路径提示： ~/.gemini/config/mcp_config.json

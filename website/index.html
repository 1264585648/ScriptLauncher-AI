Model Context Protocol Specification

内置 MCP 工具集一览（共 10 个）

启动参数：ScriptLauncher.exe mcp

工具名称 (Tool Name) 分类 功能说明与返回值
list_scripts 查询 列出所有分组与脚本入口（包含 ID、名称、脚本路径、参数、解释器模式）
execute_script 执行控制 按入口 ID 运行脚本，同步返回 {status, output, error, exitCode, durationMs}
stop_script 执行控制 安全终止正在运行的脚本及其派生的全部子进程树
create_entry / update_entry 脚本入口 创建或更新脚本入口（配置名称、路径、工作目录、启动参数、是否弹出终端等）
move_entry / delete_entry 脚本入口 将脚本入口移动到其他分组，或从本地数据库中删除指定入口
create_group / update_group / delete_group 分组管理 新建、重命名、修改图标或删除脚本分组

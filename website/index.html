专为现代开发者打造的核心特性

兼具极简直观的桌面体验与 AI 自动化调度的无限潜能。

AI-Native MCP 标准赋能

原生集成 Model Context Protocol (MCP) 服务器，暴露 10 个标准化工具接口，允许大模型在对话中直接查询、创建、修改及执行本地脚本任务。

SQLite WAL 双模共享

GUI 桌面端与后台 MCP 服务共用同一个 SQLite 数据库，开启 WAL 模式并发保障。GUI 里配置的脚本 AI 立即见，AI 写入的条目 GUI 刷新即用。

全自动多语言解释器路由

根据后缀名自动匹配解释器：Python (.py)、PowerShell (.ps1)、Node.js (.js)、Batch (.bat)、Shell 以及系统 PATH 中的任意 EXE。

Linear / Vercel 极简设计

告别老旧丑陋的控制台界面。基于现代前端美学重绘，支持深色/明亮模式、细腻悬浮动效、自适应响应式卡片网格与实时滚动抽屉。

受控的执行与安全隔离

相较于赋予大模型不受限的裸 Terminal 权限，通过 ScriptLauncher 可以结构化管理敏感运维脚本，提供清晰的入参校验与安全审计边界。

Go + Wails 独立轻量二进制

基于 Go 语言编译为单一可执行文件，毫秒级冷启动，内存占用仅数十兆，绝不依赖沉重的 Electron 或外部庞大运行时。
